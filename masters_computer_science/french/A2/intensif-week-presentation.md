# Project Goal
Create a simple, interactive HTML presentation for a French class. The presentation is a guessing game ("Devinez qui c'est ?") about two famous Indian actors. 

# Technical Requirements
- Create a single `index.html` file containing HTML, CSS, and vanilla JavaScript.
- The design should be clean, modern, and easy to read on a projector (large text, good contrast).
- Use a simple container in the center of the screen.

# Note
- Do not use any external libraries or frameworks.
- **All French must strictly stay within A1–early A2 level using simple sentences and limited grammar (qui, que, où, présent, basic passé composé).**

# Interactivity
- The page should have two sections (one for Actor 1, one for Actor 2).
- Only show one hint at a time.
- Provide a button labeled "Indice suivant" (Next hint) to reveal the next sentence.
- After all 5 hints are shown, the next button click should reveal the actor's name in a large heading and a placeholder image.
- Include a button to switch from Actor 1 to Actor 2.
