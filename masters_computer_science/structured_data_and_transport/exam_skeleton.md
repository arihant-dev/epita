### Directions

**Design a data model** for an information system which suits the given scenario.
Use the following formalism:
```text
[table name]
field: description (primary key)
field: description
...
```

The description can be empty if obvious, like when the field name is self-explanatory.
Example:
```
[User]
user_email: (primary key)
username
```

**Describe the lifecycle** of the data:
how the data model would be initialized;
how the scenario interacts with the data;
what would happen behind the scenes...
This is done in plain English, no code.

A fitting model with basic explanations gives you a passing grade;
making it 3NF-compliant improves your grade but is not mandatory.

Keep it simple! Quantity is irrelevant, only quality matters.
Original and creative ideas expanding the scenario
can boost your grade further,
as long as the basic scenario is covered
and your explanations keep the whole understandable.

> *Note:* Cybersecurity is hard and not the main focus of this course.
> For this exam, do not worry about the risk of database leaking
> and exposing passwords in your data model designs.
