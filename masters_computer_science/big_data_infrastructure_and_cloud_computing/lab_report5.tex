\section{CloudWatch Dashboard}

\subsection{Create a Dashboard for EC2 CPU and Networking Metrics}
In this part, we created a CloudWatch dashboard to monitor one EC2 instance.

\textbf{Steps performed:}
\begin{enumerate}
    \item Logged in to AWS Management Console.
    \item Opened \texttt{CloudWatch} and navigated to \texttt{Dashboards}.
    \item Clicked \texttt{Create dashboard} and provided a dashboard name.
    \item Selected widgets and chose \texttt{EC2 \textrightarrow{} Per-Instance Metrics}.
    \item Added the required CPU and networking graphs for the target instance.
\end{enumerate}

\section{CloudWatch Alarm Creation}

\subsection{Create a Billing Alarm for Estimated Charges Above \$500}
We created a billing alarm to monitor estimated AWS charges and trigger when the value goes above \$500.

\textbf{Steps performed:}
\begin{enumerate}
    \item Opened \texttt{CloudWatch \textrightarrow{} Alarms}.
    \item Selected billing metrics and created a new alarm.
    \item Set condition type to \texttt{Static}.
    \item Defined threshold as \texttt{Estimated Charges > 500 USD}.
    \item Reviewed and created the alarm.
\end{enumerate}

\labimage{figures/lab5/billing_alarm_metric_selected.png}{Billing metric selection}

\labimage{figures/lab5/billing_alarm_threshold_500.png}{Billing alarm threshold configuration}

\labimage{figures/lab5/billing_alarm_created.png}{Billing alarm created successfully}

\subsection{Create an EC2 CPU Alarm with SNS Notification (65\% Threshold)}
We also created a CPU utilization alarm for EC2. The alarm changes to \texttt{ALARM} when CPU usage is above 65\%, and SNS sends an email notification.

\textbf{Steps performed:}
\begin{enumerate}
    \item Opened \texttt{CloudWatch \textrightarrow{} Alarms} and clicked \texttt{Create Alarm}.
    \item Selected \texttt{EC2 \textrightarrow{} Per-Instance Metrics \textrightarrow{} CPUUtilization}.
    \item Set threshold to \texttt{Greater/Equal 65\%}.
    \item Created (or selected) an SNS topic for email notification.
    \item Completed alarm name, review, and alarm creation.
\end{enumerate}
